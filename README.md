# Snack Review Sentiment Analysis

Compare how customers talk about competing snack brands in Amazon reviews.

## Approach

- Review scraping with BeautifulSoup
- Sentiment scoring and text feature extraction
- Unigram, bigram and adjective analysis by brand with spaCy
